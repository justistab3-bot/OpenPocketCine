# Android 简体中文版

本次仅汉化 Android，iOS 按使用者要求不在范围内。

应用默认使用简体中文。配对、权限说明、相机列表、监看控件、云台、
设置帮助、素材回放、多机位及应用内隐私说明使用中文。品牌、专业缩写、
相机名、SSID 和文件名保留原文。未收录的提示回退至英文。
翻译仅作用于显示文案，选择值、持久化标识和相机指令保持原值。

## 安装

成品为已签名的本地调试 APK，适用于 Android 10 及以上的 arm64 手机。
包名为 `com.opencapture.openpocketcine.debug`，可与官方版并存。
它有独立的数据目录，首次使用需要重新配对相机。
应用内默认中文不修改手机的系统语言。

## 构建来源

应用层变更位于 `Apps/Android/app/src/`。共享界面的补充汉化位于
本次任务单独建立的 OpenCine 工作树，原有共享检出保持不变。
交付目录附带源码改动包，包含两个仓库的补丁及构建说明。

Windows 本地打包复用了官方 `sideload-v0.1.5-8` APK 的 Swift 核心及
Vulkan 渲染库，未重新编译这些本地库。下载的官方 APK 已与发布方的
`SHA256SUMS.txt` 核对，SHA-256 为：

```text
57e4ae2b4d130cc92ad0ef4a05b41dc4ff6bd54bb4c911dccacf963d0e57860c
```

相机核心所需的 30 个 DJI JNI 导出和 6 个应用 JNI 导出均存在。
此次共享工作树与应用所固定版本间的 Swift 相机核心源代码没有差异。
